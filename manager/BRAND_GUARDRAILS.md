# 壶中天机｜AI Website Manager 品牌与发布护栏

## 锁定资料

- 正式品牌：**壶中天机 / HUZHONG TIANJI**
- 网站主识别必须使用完整正式 Logo；小尺寸 favicon 才可只用图形标记。
- 官方 WhatsApp：**+65 8014 8899**（链接数字：`6580148899`）。
- 主要互动入口：**HU Zhong Compass／壶中罗盘**、**壶中日签／今日天机**。
- 网站体验：中文与英文并行，语气温和、清楚、不制造恐惧。

## 可以自动执行

1. 网站可用性、速度、断链、Logo、WhatsApp 号码与基本 SEO 检查。
2. 建立健康报告、备份包和异常 GitHub Issue。
3. 根据题目生成内容**草稿**，建立 Draft Pull Request。
4. 检查草稿是否含免责声明、是否误放 API key、是否缺少人工审批标记。

## 不得自动发布

以下内容必须经过人工查看并手动合并 Pull Request：

- 服务价格、Stripe／付款链接、退款政策与法律条款。
- 客户姓名、出生资料、订单资料、WhatsApp 对话或任何个人资料。
- 医疗、法律、投资与财务结论。
- “保证发生”“一定发财”“一定结婚”“必有灾祸”等绝对化命理表述。
- 对外品牌声明、合作伙伴名称、客户案例及任何保密项目。
- 删除页面、改变主要功能、切换 AI 模型或更改 API 权限。

## 内容原则

- 清楚区分传统文化解读、现实事实与行动建议。
- 命理内容使用“倾向、可能、参考、适合留意”等概率语言。
- 不用恐惧推动成交，不以灾祸或疾病制造紧迫感。
- 每篇命理／传统文化内容保留：
  - “传统文化与个人参考”声明；
  - 不替代医疗、法律、投资或其他专业意见的说明；
  - 温和、现实可执行的 CTA。
- 中英文内容应保持相同意思，不做机械直译。

## 发布流程

`AI 草稿 → 自动护栏检查 → Draft PR → 人工审阅 → Deploy Preview → 人工合并 → Netlify 正式部署`

AI Website Manager 不直接把内容推送到 `main`，也不自动合并 PR。
